# Console fonts

## terminus-14.psf

- Source: [powerline/fonts](https://github.com/powerline/fonts/tree/master/Terminus/PSF) (`ter-powerline-v14n.psf.gz`, decompressed)
- Original font: Terminus Font (SIL Open Font License 1.1)
- Format: PSF2 with Unicode table, 8×14 glyphs

To swap fonts, replace this file with any PSF2 that has the `PSF2_HAS_UNICODE_TABLE` flag set, then rebuild the kernel.
